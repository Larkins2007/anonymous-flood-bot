# Smoke test

## 1. Проверка запуска

```bash
python -m py_compile bot.py
pytest -q
```

Ожидаемый результат: все тесты проходят.

## 2. Проверка группы

1. Добавьте бота в тестовую группу.
2. Выдайте ему права, необходимые для ограничения участников и управления Telegram member tags.
3. Проверьте `/help@justice_faite_bot`.
4. Проверьте `/roles@justice_faite_bot`.
5. Проверьте `/me@justice_faite_bot`.
6. Проверьте `/mafia@justice_faite_bot`.

## 3. Новый участник

1. Новый пользователь входит в группу.
2. Бот отправляет welcome и ограничивает отправку сообщений.
3. Пользователь нажимает `Я ознакомлен(а) с правилами`.
4. Бот снимает ограничение.
5. В ЛС владельцу приходит уведомление о подтверждении.
6. Пользователь может писать в чате.

## 4. Роль

Для свежего участника:

```text
калл Кокоми
```

или ответом на сообщение участника:

```text
калл Кокоми
```

Проверить, что Telegram member tag установлен.

## 5. Mafia

1. `/mafia` создаёт и закрепляет lobby.
2. Кнопки `Войти` / `Выйти` меняют одно и то же сообщение.
3. После пяти участников lobby удаляется.
4. Бот отправляет `/start@MafiaAzBot`.
5. Если пять участников не набраны за 5 минут, lobby удаляется автоматически.

## 6. Уход

1. Участник выходит.
2. Welcome не отправляется.
3. Старое welcome удаляется.
4. В ЛС владельцу приходит последняя известная роль и тег участника.
