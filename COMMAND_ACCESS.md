# Гибкая настройка команд Justice Faite

## Где находится панель

Открой личные сообщения с ботом и отправь `/settings`. Панель доступна только владельцу бота. Она содержит 279 индивидуальных карточек команд и 3 карточки фоновых функций. Изменения применяются сразу, перезапуск не требуется.

В главном меню доступны категории, поиск команды, краткое руководство, журнал изменений и обновление меню Telegram. Команду можно найти по названию, ключу, slash-команде или текстовому алиасу. Например: `бан`, `мут`, `+ссылки`, `/spy`, `кланы`.

## Настройки одной команды

Открой категорию, затем карточку нужной команды. Общие параметры одинаковы для всех команд:

| Параметр | Значение |
|---|---|
| Команда включена | Включена или полностью отключена |
| Кто может вызывать | Все, участники текущего чата, администраторы Telegram, внутренний ранг от 1-го до 5-го или владелец бота |
| Где работает | Только ЛС, только группа или оба места, если у команды действительно есть обработчик в обоих местах |
| В каких группах | Основной чат или все доступные группы, если команда поддерживает мультичаты |
| Пауза между вызовами | От 0 до 3600 секунд, отдельно для каждого пользователя и чата |
| Удалять сообщение команды | От 0 до 600 секунд; требует права удаления сообщений |
| Собственные параметры | Специальные параметры конкретной команды: лимиты, тексты, сроки, режимы и т. п. |

Некоторые команды поддерживают не все места использования. Поэтому панель показывает только реальные варианты, в которых зарегистрирован обработчик. Например, личная консоль не может быть включена для группы, а команду, работающую только во флуде, нельзя перенести в личку простой настройкой.

## Уровни доступа

- **Все** — любой пользователь, который может обратиться к боту в указанном месте.
- **Участники** — только участники именно того Telegram-чата, в котором вызвана команда.
- **Администраторы Telegram** — администраторы текущей группы. Этот критерий основан на статусе и правах Telegram.
- **С 1-го…5-го ранга** — внутренние ранги Justice Faite. Доступ получают выбранный ранг и все ранги выше него.
- **Владелец бота** — только Telegram ID, заданный через `ADMIN_ID`.

Статус администратора Telegram и внутренний ранг Justice Faite не тождественны. Настройка «Администраторы Telegram» проверяет только Telegram-статус. Настройки «С 1-го…5-го ранга» проверяют только явно назначенный в базе Justice Faite ранг; разрешения Telegram сами по себе не повышают его. И наоборот, внутренний ранг не выдаёт Telegram-права на удаление сообщений или блокировку.

## Полное отключение и тихое поведение

Если снять переключатель «Команда включена», бот прекращает обработку этой команды до вызова её основного обработчика. Это действует также на владельца бота, кроме аварийной панели `/settings` в личке владельца.

Отключённая команда:

- не отвечает текстом о запрете;
- не сообщает, что команда отключена;
- не выполняет действие;
- не делает лишний запрос `getChatMember` перед отклонением;
- исчезает из `/help` и доступного меню slash-команд Telegram после обновления меню.

Для callback-кнопок отключённое действие тоже не выполняется. Telegram получает пустой callback-answer, чтобы убрать индикатор ожидания, без всплывающего предупреждения.

Команды, для которых не хватает ранга или которые вызваны не в том месте, в группах также отклоняются без служебного сообщения. В личке при обычном ограничении доступа бот может объяснить причину. Полное отключение и личный запрет всегда остаются тихими.

## Персональные исключения

В карточке команды открой «Индивидуальный доступ».

Можно добавить Telegram ID с одним из режимов:

- **Разрешить** — обойти обычный ранговый порог для этого пользователя.
- **Запретить** — запретить пользоваться командой, даже если у человека высокий ранг.
- **Сбросить** — удалить исключение и вернуть общие правила.

Форматы ID:

- `123456789` — действует во всех чатах;
- `123456789@-1001234567890` — действует только в указанной группе.

Исключение «Разрешить» не может включить полностью отключённую команду и не обходит ограничение по месту использования или области чатов. Исключение «Запретить» имеет приоритет над обычным уровнем доступа. Все изменения записываются в журнал.

## Совместимость с командой «ДК»

Старая команда модерации `ДК` сохранена как короткий способ поменять ранг для команды:

- `ДК бан 0` — разрешить всем;
- `ДК бан 1` — разрешить с внутреннего 1-го ранга и выше;
- `ДК бан 3` — разрешить с 3-го ранга и выше;
- `ДК бан 5` — только 5-й ранг;
- `ДК бан 6` — полностью отключить команду.

Вместо `бан` можно указывать алиас, название или slash-команду из реестра, например `ДК /spy 3`. Изменение происходит в общей системе и сразу отражается в `/settings`. Для выбора Telegram-администраторов, участников, места, паузы, персональных исключений и собственных параметров используй `/settings`.

## Журнал изменений

В главном меню панели есть «История изменений». В ней фиксируются:

- изменение любого параметра команды;
- включение и отключение;
- смена уровня доступа и места работы;
- создание, изменение и удаление персональных исключений.

Журнал показывает старое и новое значение, ID администратора и время изменения. В панели показываются последние 100 записей с перелистыванием.

## Командное меню Telegram и справка

После изменения включения, уровня доступа, места использования или области групп бот автоматически обновляет меню slash-команд. Отключённые команды исключаются из меню. `/help` формируется с учётом доступности конкретному пользователю в текущем чате.

Telegram-командное меню поддерживает только slash-команды. Текстовые алиасы (например, `Бан`, `Кланы`, `+Заметка`) остаются доступны через обычное сообщение и учитываются общей проверкой доступа.

## Свои команды

Пользовательские команды создаются через `/settings` → «Свои команды». После сохранения каждая команда получает собственную карточку с общими параметрами и настройкой текста ответа, описания и режима ответа. Удаление такой команды удаляет её карточку и индивидуальные настройки.

## Безопасность и ограничения

Центральная политика доступа решает, можно ли вызывать функцию. Внутренние проверки владения ресурсом и иерархии остаются обязательными: например, нельзя удалить чужой клан/сетку или изменить права модератора равного либо более высокого ранга, если пользователь не имеет полномочий на эти данные. Настройка «Все» не превращает обычного участника в Telegram-администратора и не наделяет бота дополнительными правами.

Настройки хранятся в общей SQLite-базе бота. Для Render Free локальная база может потеряться при перезапуске или redeploy; одна лишь панель команд не заменяет постоянную БД или диск. Перед боевым запуском используй постоянное хранилище и резервное копирование.

## Проверка

Офлайн-проверки запускаются командой:

```bash
python3 -m compileall -q .
python3 tests/run_all.py
```

Набор тестов покрывает реестр команд и алиасы, ранговую модель, тихое отключение в личке и группе, ограничения по месту и области чатов, персональные исключения, кнопки, паузы, обновление меню и совместимость с `ДК`. Офлайн-тесты не заменяют проверку с реальным токеном Telegram в тестовой группе.

## Новые команды 0.7.2–0.7.3

- `взять рест на 7 дней` / `/take_rest на 7 дней` — участник оформляет рест только на себя. Разрешённый максимум настраивается в карточке команды, по умолчанию 14 дней. Также поддерживается дата окончания, например `взять рест до 15.11`.
- `др 24.03` / `др 24 марта` — участник сохраняет собственную дату рождения прямо в основном флуде; `др удалить` удаляет её. Команда `/jf_birthday` продолжает работать в личке.


## Команды категорий игры «Шпион» (0.7.3)

- `/spy_categories` — показать доступные встроенные и пользовательские категории.
- `/spy_category места, предметы` — выбрать категории текущего лобби; доступно создателю лобби и администраторам.
- `/spy_word_add категория | слово | алиасы | подсказки` — добавить слово в пользовательский набор текущей группы.
- `/spy_word_remove категория | слово` — удалить пользовательское слово. Встроенные слова не удаляются.
- `/spy_leave` — выйти из лобби до начала раздачи секретных карточек.


## Личные команды владельца и общий флуд

Команды `/jf_console`, `/jf_console_refresh`, `/jf_memory`, `/jf_memory_save`, `/jf_memory_search` и `/jf_chatlog` принадлежат только владельцу и предназначены для личного чата с ботом. В меню команд общего чата они не отображаются.

Если владелец случайно отправляет одну из них в основной флуд, бот сначала удаляет исходное сообщение и затем выполняет команду так, чтобы все карточки и ответы пришли в личный чат `ADMIN_ID`. Текст таких команд не добавляется в архив переписки флуда. Если удалить исходное сообщение не удалось, команда не выполняется; владелец получает предупреждение в личке. Для перенаправления из группы бот должен иметь право удалять сообщения (`can_delete_messages` в супергруппе).

`ADMIN_ID` в настройках хостинга должен быть числовым Telegram ID владельца без символа `@`. Все сообщения консоли принудительно направляются в этот личный чат, даже если вызывающий код ошибочно передал ID группы.
