# Advisor и Watch 0.14.0 — документ изменений

## Реализовано в локальной сборке

- Локальная статистика Advisor без Groq на основе `jf_chat_message_log`, `jf_stats_daily`, `jf_reports`/`reports`, `spy_players`, `mafia_players` и `jf_ai_watch_alerts`.
- В отчётах: сообщения, авторы, активные часы и дни недели, тихие периоды, динамика сообщений и активных авторов при достаточной истории, игровые участия, обращения и категории Watch. При недостатке данных это явно указано.
- Управляемое расписание в существующей `jf_ai_analytics_state`; владелец меняет интервал и час через `/jf_ai_schedule`.
- Состояния доставки отчётов и сигналов, максимум 5 попыток с экспоненциальной задержкой.
- Локальные формальные сигналы 10.1, 9.1, 4.4 и консервативная проверка 2.6 с reply-связью и совпадающим повтором.
- Скользящая агрегация reply/mention-пар за 72 часа; псевдонимы пар и счётчики, без идентификаторов для модели.
- Повторные семантические сигналы объединяются в одну запись, если адресат достоверно выводится из reply-связи; иначе остаются отдельными.
- Обычные сигналы отправляются сводкой; срочные сигналы высокого уровня по правилам 2.1/2.2/2.5 ограничены тремя в час.
- Срок хранения Watch настраивается `/jf_ai_schedule retention 1..365`, по умолчанию наследует `JF_CHAT_LOG_RETENTION_DAYS`.
- Очистка только архива Watch доступна через `/jf_ai_watch_clear` и отдельное подтверждение `/jf_ai_watch_clear confirm`.

## Ограничения

- Срочные уведомления о технических сбоях/остановке аналитики/потере доступа к БД не добавлены в этот этап.
- Накопление семантических сигналов по адресату возможно только при наличии локальной reply-связи; одного упоминания недостаточно, чтобы достоверно определить адресата.
- Игровое участие учитывается только по существующим `spy_players` и `mafia_players`; опросы не приравниваются к посещению мероприятия.
- Показатели динамики интереса требуют как минимум шести дневных агрегатов; иначе отчёт пишет, что базы сравнения недостаточно.

ИИ не применяет санкции, не меняет роли/предупреждения и не принимает кадровых решений. Все сигналы предназначены только владельцу.
