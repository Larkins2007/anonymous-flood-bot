# Проверка личных команд владельца — 0.8.4

Проверены все шесть команд, которые владелец перечислил в обращении. Это отдельная группа служебных команд личной консоли, а не пользовательские команды общего флуд-чата.

| Команда | Что выполняет | Куда отправляет результат |
|---|---|---|
| `/jf_console` | Создаёт/обновляет пять карточек: система, игры, модули, роли, память; присылает подтверждение | Только ЛС владельца |
| `/jf_console_refresh` | Повторно обновляет все пять карточек | Только ЛС владельца |
| `/jf_memory` | Показывает структурированную память, последние личные заметки владельца, фрагменты архива флуда и техлог | Только ЛС владельца |
| `/jf_memory_save категория \| заголовок \| текст` | Сохраняет/обновляет запись SQLite, обновляет консоль, присылает подтверждение | Только ЛС владельца |
| `/jf_memory_search запрос` | Ищет по памяти проекта, личным заметкам, архиву флуда и техническим логам; запрос должен быть не короче 2 символов | Только ЛС владельца |
| `/jf_chatlog` | Показывает количество архивных сообщений и техлогов, период хранения и дату последней записи | Только ЛС владельца |

## Правила доступа и маршрутизации

- Все шесть команд имеют политику `owner` и `private`; в меню команд общего чата они не показываются.
- В личке команды обрабатываются штатными обработчиками и проверяют совпадение `from_user.id` с `ADMIN_ID`.
- Если владелец случайно отправляет команду в основной флуд, бот удаляет исходное сообщение и выполняет ту же команду через частный контекст. Ответы и все карточки консоли уходят только на `ADMIN_ID`.
- Если сообщение нельзя удалить, команда не выполняется. Владелец получает предупреждение в ЛС; в группе бот не публикует результаты консоли.
- Команды владельца из основного флуда не записываются в архив переписки; это предотвращает сохранение текста `/jf_memory_save` в общем архиве.
- Адрес любой карточки консоли принудительно нормализуется до `ADMIN_ID`; передать ID группы как адрес консоли больше нельзя.

## Требования к Render и Telegram

- `ADMIN_ID` должен быть установлен в Render → Environment как числовой Telegram ID владельца без `@`.
- Для перенаправления команд из супергруппы у бота должно быть право администратора `can_delete_messages`.
- Владелец должен хотя бы один раз открыть личный чат с ботом и нажать Start, чтобы Telegram разрешил боту отправлять туда сообщения.
- Если команда отправлена напрямую в личке, право удаления сообщений в группе не требуется.

## Офлайн-проверки этой правки

Пройдены:

- `python -m compileall -q .`
- `python tests/test_console.py`
- `python tests/test_command_access.py`
- `python tests/test_settings_panel.py`
- `python tests/test_startup_safety.py`
- `python tests/test_roles.py`
- `python tests/test_ui.py`

Тесты используют локальную SQLite и заглушки aiogram. Они проверяют маршрутизацию всех шести команд, отсутствие их в групповом меню, удаление группового вызова, приватную доставку всех результатов, отказ при невозможности удалить команду и блокировку публикации карточек в группу. Они не являются проверкой токена, переменных окружения и живого Render/Telegram-сервиса.
