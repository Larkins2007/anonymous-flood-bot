# Обновление Justice Faite Manager до 0.8.2

1. Сделайте копию текущего ZIP/исходников. Не удаляйте закреплённую резервную копию `JF_DB_BACKUP_V1` в личном чате бота.
2. Замените файлы приложения содержимым архива v0.8.2. Не удаляйте переменные окружения Render и не меняйте `ADMIN_ID`.
3. Убедитесь, что `JF_ALLOW_EMPTY_DB_BOOTSTRAP` остаётся `false` (или не задан). Не включайте его для обхода ошибки восстановления существующей базы.
4. Запустите Deploy на Render и проверьте логи: при успешном восстановлении должна появиться запись `Recovered SQLite database from the pinned owner-DM backup`, после чего приложение продолжит инициализацию.
5. После старта проверьте данные через личную консоль бота. Файл `users.db.corrupt.<timestamp>` оставьте до подтверждения, что данные восстановились полностью.

Изменения схемы БД в этой версии не требуются. Эта сборка устраняет ошибку `Invalid cross-device link`; фактическое восстановление зависит от доступности и корректности закреплённой резервной копии Telegram. Живой запуск на вашем Render-сервисе из среды разработки не выполнялся.
