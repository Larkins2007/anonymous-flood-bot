# Обновление Justice Faite Manager до 0.8.5

1. Сделайте резервную копию текущей SQLite-базы и текущей папки проекта.
2. Замените файлы проекта содержимым полного архива `Justice-Faite-Manager-v0.8.5.zip`.
3. Переменные окружения и секреты из `.env` / панели хостинга не заменяйте значениями из примеров.
4. Перезапустите бота. Для исправления панели отдельная миграция пользовательских настроек не требуется: существующие `cmd_settings` и `cmd_feature_switches` сохраняются.
5. Откройте `/settings` в личке владельца. 🟢 — команда действует; ⚫ — выключена в своей карточке; 🟡 — личное состояние включено, но команда приостановлена общим режимом или разделом.
6. Проверьте: выключение раздела не стирает переключатели команд; обратное включение раздела восстанавливает прежние индивидуальные состояния; верхняя кнопка команды — единственное место для переключения `Команда включена`.
7. Старые карточки с предыдущими кнопками переключения могут показывать предупреждение «кнопка устарела». Это намеренно: откройте `/settings` заново, чтобы получить новые кнопки с однозначным действием.

**Важно:** перед заменой на основном хостинге сохраните текущую базу. Офлайн-тесты прошли на SQLite и заглушках Telegram; реальный Bot API/Render в этой проверке не запускался.
