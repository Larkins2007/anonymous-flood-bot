# Обновление Justice Faite Manager до 0.8.1

## Что добавлено

1. `/inline_guard` в личке владельца: управление защитой от inline-ботов в основном флуде.
2. Режимы: выключено, выбранные usernames, все inline-боты.
3. Определение источника через `Message.via_bot`; поиск по словам и упоминаниям не используется.
4. Журнал удалений/ошибок без сохранения содержимого сообщения (последние 500 событий).
5. В `/settings`: выключение всех пользовательских команд или отдельного раздела с подтверждением и сохранением индивидуальных настроек.
6. Глобальные и разделовые переключатели записываются в SQLite и журнал изменений.

## Условия работы inline-защиты

- Перед включением панель проверяет, что бот — администратор основного супергруппового чата и имеет право `can_delete_messages`; если права отсутствуют, защита не включается.
- Переход в режим «все inline-боты» требует отдельного подтверждения. В панели есть журнал последних действий и кнопка проверки разрешений.
- Telegram Bot API должен доставлять боту сообщения с полем `via_bot`.
- При совпадении сообщение не передаётся последующим обработчикам даже тогда, когда удаление не удалось; подробность отказа появляется в техжурнале.
- Удаление через Bot API возможно для сообщений моложе 48 часов; обработчик работает сразу после получения обновления.

## Обновление

1. Скачайте текущую резервную копию SQLite до замены кода.
2. Замените файлы приложения содержимым архива v0.8.1, не удаляя `users.db`, `.env` и секреты окружения.
3. Убедитесь, что `ADMIN_ID` и `PRIMARY_CHAT_ID` заданы правильно; `DB_PATH` должен указывать на постоянный диск, если хостинг поддерживает его.
4. Запустите бота и проверьте `/settings`, `/inline_guard` и тестовое сообщение от inline-бота в отдельной тестовой группе.
5. Проверьте свежий backup в личке владельца.

Существующие таблицы и данные не удаляются. Новые таблицы создаются через `CREATE TABLE IF NOT EXISTS`; старые базы автоматически получают недостающую схему после проверки и восстановления.

## Проверки

`python -m compileall -q .` и `python tests/run_all.py`. Результаты локальных тестов не заменяют live-проверку с Telegram API и реальным Render deployment.
