# Обновление Justice Faite Manager до 0.15.2

0.15.2 исправляет диагностику ошибок AI-провайдера. В частности, исчерпание API-кредитов больше не маскируется под обычный временный лимит запросов.

## Что исправлено

1. HTTP 429 с признаками `You have no credits remaining`, `insufficient_quota`, `billing_limit` и похожими теперь классифицируется как исчерпание кредитов/биллинг.
2. Обычные rate limits (частота запросов/токенов) отдельно классифицируются как временное ограничение.
3. Ошибки 401/403, 404 и 5xx получают отдельные понятные ответы.
4. Парсер читает JSON и plain-text ошибки OpenAI-compatible endpoint. Содержимое ответа провайдера, API-ключ и billing URL не отправляются в групповой чат.
5. Команда `/jf_ai` в реальном личном чате владельца показывает hostname endpoint и имя модели. API-ключ и полный URL не раскрываются.

## Что показала диагностика перед выпуском

В предоставленной копии SQLite найдено исключение AI-запроса с HTTP 429 и сообщением провайдера `You have no credits remaining`, а также ссылкой на страницу биллинга `platform.openai.com`. Это указывает на исчерпание кредитов/лимита оплаты у endpoint, который обслуживал запрос. В самой SQLite не хранится `JF_AI_BASE_URL` из окружения Render, поэтому точный настроенный hostname нельзя подтвердить по одной базе.

В архиве проекта значение по умолчанию — Groq endpoint `https://api.groq.com/openai/v1/chat/completions`; Render Environment может переопределить его через `JF_AI_BASE_URL`. После установки этой версии отправьте `/jf_ai` именно в личный чат владельца и сверьте показанный hostname и модель с выбранным провайдером. Не вставляйте API-ключ в чат, логи или скриншоты.

## Установка и действия администратора

1. Сделайте отдельную резервную копию production SQLite и сохраните текущие переменные окружения. Архив проекта не содержит пользовательскую базу и не заменяет её.
2. Обновите код до 0.15.2 и перезапустите только один экземпляр Telegram polling-процесса.
3. В личном чате владельца выполните `/jf_ai`; проверьте endpoint hostname и модель.
4. В Render Environment сверьте `JF_AI_BASE_URL`, `JF_AI_MODEL`, `JF_AI_ENABLED` и наличие `JF_AI_API_KEY`. Ключ должен оставаться секретом Render.
5. Если hostname относится к OpenAI или другому платному API, администратор аккаунта должен проверить доступный кредит/биллинг у этого провайдера либо настроить endpoint провайдера, у которого есть действующий доступ и кредит. Само обновление кода не добавляет средства на API-баланс.
6. Если endpoint — Groq, проверьте ключ и баланс/доступ именно в Groq Console. Не используйте модель одного провайдера с endpoint другого без подтверждения совместимости.
7. Проверьте коротким тестом в группе: `Джастис, скажи, что Казуха грубый`. При отсутствии кредитов бот должен назвать именно эту причину, а не общую ошибку.

## Дополнительное замечание из runtime log

В SQLite также есть `TelegramConflictError: terminated by other getUpdates request`. Это отдельная проблема: вероятно, одновременно работали два процесса polling одного bot token. Для Telegram polling должен работать ровно один активный экземпляр. Проверить число web/worker/background services и старые запущенные процессы нужно отдельно.

## Безопасность и границы

- Проверка выполнена на локальной копии кода и read-only копии БД.
- Пользовательские записи/роли/память/журнал не менялись.
- API-запрос с реальным ключом не запускался; биллинг не изменялся.
- Commit, push и deployment не выполнялись.
