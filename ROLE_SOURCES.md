# Role naming verification notes

The English role names were cross-checked against current official Genshin Impact / HoYoLAB material for the current roster, especially newer characters and the 2025–2026 Nod-Krai/Snezhnaya additions.

Examples of direct official confirmations used during the build include:

- Prune — Genshin Impact Official character introduction and trailer.
- Lohen — Genshin Impact Official character introduction/trailer and Event Wish notice.
- Varesa — Genshin Impact Official character introduction.
- Dahlia — Genshin Impact Official character introduction and character material.
- Lauma — Genshin Impact Official character introduction / event material.
- Aino — Genshin Impact Official material.
- Nefer — Genshin Impact Official character material.

For older established characters, the English names are the standard canonical forms used by HoYoverse. For lore-only entries in the user's roster, the catalog preserves established English story names (for example Hroptatyr, Vedrfolnir, Rerir and Surtalogi) rather than inventing alternatives.
