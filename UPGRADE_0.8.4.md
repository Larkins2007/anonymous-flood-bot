# Обновление Justice Faite Manager до 0.8.4

1. Скачайте и распакуйте полный архив v0.8.4.
2. Замените файлы проекта в GitHub содержимым архива. Не удаляйте и не переименовывайте базу данных, закреплённую резервную копию `JF_DB_BACKUP_V1` и переменные окружения Render.
3. Проверьте, что `ADMIN_ID` в Render → Environment содержит только числовой Telegram ID владельца, без `@`. Не вставляйте ID в `BOT_TOKEN` или `PRIMARY_CHAT_ID`.
4. Выдайте боту в основном флуде право удалять сообщения. Без этого правообладатель сможет пользоваться командами в ЛС, но команды, случайно отправленные в группу, не будут перенаправляться.
5. Выполните Deploy. После запуска отправляйте команды в личку бота. Если случайно отправить их в основной флуд, бот удалит исходное сообщение и отправит результат в ЛС владельца.

Команды личной консоли: `/jf_console`, `/jf_console_refresh`, `/jf_memory`, `/jf_memory_save категория | заголовок | текст`, `/jf_memory_search запрос`, `/jf_chatlog`.

Схема SQLite не меняется. Новые офлайн-тесты используют локальные SQLite и заглушки aiogram; реальный Render и Telegram API из среды разработки не запускались.
