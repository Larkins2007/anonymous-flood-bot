# Justice Faite Manager 0.24.0

## Изменения

- `/help` в основном чате теперь даёт короткий переход в личный справочник. `/start help` открывает подробные описания доступных пользователю команд.
- Добавлены owner-only команды `/roleid` и `/roleid_remove` для привязки персонажа к числовому Telegram ID.
- `/syncroles` сохраняет старую синхронизацию Telegram-тегов и дополнительно сверяет зарегистрированные ID с основным чатом. При подтверждённом присутствии участника роль помечается 💛, при подтверждённом выходе сердечко снимается. Неопределённые статусы не трактуются как выход.
- Список обновляется в публикациях информационного канала `@Justice_faite`, сообщения 40 и 41. Канал можно изменить через `ROLE_INFO_CHANNEL`.
- Justice AI вызывается только сообщением, начинающимся с `Джастис `, без запятой. Обращения «помощник» и «Джастис,» не запускают AI.
- Уточнены инструкции AI по связности разговора, коротким репликам, адресатам и неопределённости.

## Привязка ролей

В личном диалоге с ботом владелец отправляет:

```text
/roleid Аль-Хайтам — 123456789
/roleid Кэйя — 987654321
```

Для массовой загрузки передай несколько строк в одном сообщении после `/roleid`. Числовые ID должны быть получены от владельца; бот не пытается угадывать их по именам или username. Один Telegram ID может быть привязан только к одной персонажной роли.

Затем вызови `/syncroles`. Бот должен иметь право редактировать сообщения 40 и 41 в информационном канале и иметь возможность проверять участников основного чата. До первой успешной регистрации ID публикации не меняются.

## Ограничения и проверка

- Telegram Bot API не предоставляет транзакционное редактирование двух сообщений. Если первое редактирование прошло, а второе завершилось ошибкой, отчёт явно покажет частичный результат.
- При ошибках проверки статусов публикации не редактируются, чтобы временная недоступность Telegram не сняла занятые отметки.
- Владелец должен сам предоставить соответствия «персонаж — Telegram ID».
- Перестройка всех исходников в один файл намеренно не выполнялась: это увеличило бы связанность и риск регрессий. Сокращать стоит только действительно мелкие вспомогательные модули после отдельного аудита импортов.
