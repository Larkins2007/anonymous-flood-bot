# Justice faite bot

Telegram-бот на aiogram 3 для анонимной обратной связи, жалоб, админки, управления ролями участников и lobby для запуска отдельного MafiaAzBot.

## Пользовательские команды

- `/help` — список возможностей
- `/roles` — кто сейчас носит назначенную роль
- `/me` — своя роль и Telegram-тег
- `/mafia` — открыть lobby MafiaAzBot
- `/mafia_leave` — выйти из lobby

## Команды администратора

- `/setrole` — назначить роль участнику
- `/release` — снять роль
- `/syncroles` — сверить реальные Telegram-теги с локальной информацией
- `/member` — информация об участнике
- `/pending` — новые участники, ещё не подтвердившие правила
- `/mafia_ban` / `/mafia_unban` — управление запретом участия в MafiaAzBot

## «Флудик»

Бот принимает естественные обращения, если сообщение начинается со слова `флудик`.

Примеры:

```text
флудик помощь
флудик покажи роли
флудик какая у меня роль
флудик начни мафию
флудик статус
флудик сколько игроков
флудик я выхожу из мафии
флудик назначь роль Кокоми
флудик освободи роль Кокоми
флудик синхронизируй роли
флудик кто ждёт
флудик информация @username
флудик запрети мафию @username
флудик разреши мафию @username
```

## Вход участников

После входа новый участник получает ограничение на отправку сообщений и приветственное сообщение с кнопкой подтверждения правил.

Кнопка означает, что человек ознакомлен с правилами сообщества и самостоятельно несёт ответственность за свои действия и сообщения.

После подтверждения бот снимает ограничение и отправляет владельцу уведомление с именем, ID, ролью и тегом участника.

При выходе бот сообщает владельцу последнюю известную роль и Telegram-тег участника.

## Роли

В каталоге 148 ролей.

Назначение можно делать:

```text
калл Кокоми
калл @username Кокоми
```

или командой `/setrole` / кнопкой назначения роли.

`калл` здесь используется только как shortcut назначения роли и не вмешивается в работу другого бота, который использует это слово для созыва.

Внешний список ролей бот не редактирует и не синхронизирует.

## MafiaAzBot

Наш бот не ведёт саму игру. Он только создаёт lobby:

```text
1/5 → 2/5 → 3/5 → 4/5 → 5/5
```

Lobby закрепляется, обновляется при входе/выходе и удаляется через 5 минут, если минимум не набран. После пятого игрока lobby удаляется и бот передаёт запуск другому боту через:

```text
/start@MafiaAzBot
```

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

Нужна переменная окружения `BOT_TOKEN`.

Для полноценной работы групповых текстовых shortcut'ов (`калл`, `флудик`) отключите Privacy Mode в BotFather.

## Render

Start Command:

```text
python bot.py
```

Бот поднимает `/health` на `PORT` (по умолчанию `10000`).
