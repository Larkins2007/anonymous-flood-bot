# Justice Faite Bot

Telegram-бот на aiogram 3.x для анонимной обратной связи, жалоб, админского управления, ролей/Telegram-тегов и лобби MafiaAzBot.

## Основные функции

- Anonymous feedback и reports.
- Ролевая система из 148 ролей.
- Назначение роли администратором через `калл <роль>` для нового участника.
- Telegram member tags через `setChatMemberTag`.
- Новый участник ограничен до подтверждения правил; снять ограничение можно назначением роли через `калл <роль>`.
- Кнопка подтверждения фиксирует ознакомление с правилами флуда и уведомляет владельца.
- `/roles` и `/me` работают по локальному состоянию участника и назначенной роли.
- `флудик ...` — естественный префикс для доступных команд.
- `/manage_commands`, `/addcommand`, `/delcommand`, `/commands` — управление пользовательскими командами прямо из ЛС владельца.
- Mafia lobby: минимум 5 игроков, автоматическая передача через `/start@MafiaAzBot`, удаление lobby через 5 минут при недоборе.

Внешний список ролей и автоматическое редактирование чужих сообщений больше не используются.

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

Обязательная переменная:

```text
BOT_TOKEN
```

Рекомендуется задать `DB_PATH` на постоянное хранилище, если платформа деплоя использует эфемерный filesystem.
