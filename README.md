# Justice Faite Bot

Telegram-бот на **aiogram 3 + SQLite**. Основные модули: `bot.py` и `justice_features.py`.

## Что важно в этой сборке

- **Нет входа во флуд через бота.** В личном меню нет кнопки заявки; обработчики заявок и `chat_join_request` не регистрируются. Добавление участников выполняется администрацией отдельно, вне этого бота. Старые таблицы заявок/приглашений в SQLite сохранены только для совместимости со старыми базами и не используются активным сценарием.
- **Нет автоматических сообщений об играх.** `schedule_worker()` отключён и не публикует сообщения в основной чат. Лобби и действия игр остаются пользовательскими.
- **Персональные настройки команд.** `/admin` или `/panel` → «Настройки команд». Каждую команду можно включить/отключить отдельно. Настройки хранятся в SQLite. Базовые проверки прав в обработчиках остаются обязательными; выключение команды действует глобально.
- **Ручная выдача наград Ирис.** Бот не пытается общаться с Ирис от имени другого бота и не отправляет команды наград в группу. Используй `/jf_awards`, затем отправь Ирис `!олды` в основном флуде и перешли её ответ в личные сообщения бота. Бот покажет общий список «кому какую награду выдать», затем пришлёт отдельные команды для ручной пересылки. Если какие-то строки не удастся безопасно сопоставить, бот отдельно перечислит их; он не будет угадывать получателя. Перешли каждую команду во флуд вручную. После успешной отправки нажми «Отметить выданной» под соответствующей командой. Это локальная отметка, а не подтверждение от Ирис.
- **Настройки секретов только через окружение.** Не присылай токен бота в чат и не храни его в исходниках.

## Команды

Полный список и краткое назначение — в [`COMMANDS.md`](COMMANDS.md). Основные:

- `/start`, `/help`, `/anon`
- `/mafia`, `/mafia_leave`, `/spy`, `/spy_kick`, `/spy_end`, `/game_poll`
- `/setrole`, `/syncroles`, `/bindrole`, `/roles_audit`
- `/admin`, `/panel`, `/jf_dashboard`
- `/jf_awards`, `/jf_iris_sync`, `/jf_award`
- `/jf_warn`, `/jf_warnings`, `/jf_warn_remove`
- `/rest`, `/jf_restlist`
- `/jf_birthday`, `/jf_birthdays`
- `/manage_commands`, `/addcommand`, `/delcommand`, `/commands`

## Переменные окружения

Обязательные:

- `BOT_TOKEN`
- `ADMIN_ID` — Telegram ID владельца
- `PRIMARY_CHAT_ID` — ID основного флуд-чата, обычно `-100...`

Необязательные:

- `DB_PATH` — SQLite-файл, по умолчанию `users.db`
- `PORT` — порт health endpoint, по умолчанию `10000`
- `JF_RULES_URL` — оставлено для совместимости, но бот больше не принимает заявки на вступление
- `IRIS_AWARD_COMMAND` — название команды Ирис, по умолчанию `наградить`
- `IRIS_AWARD_PREFIX` — префикс команды, по умолчанию `!`
- `IRIS_30D_AWARD_LEVEL`, `IRIS_60D_AWARD_LEVEL`, `IRIS_120D_AWARD_LEVEL` — уровни наград за стаж

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

## Офлайн-проверки

```bash
python -m py_compile bot.py justice_features.py tests/simulation.py
python tests/simulation.py
```

Офлайн-проверки не заменяют проверку в Telegram. Для live smoke-test нужны действительные переменные окружения и доступ бота к тестовому чату. Не используйте рабочий флуд для первичного тестирования.
