# Justice Faite Bot

Telegram-бот на aiogram 3.x для анонимной обратной связи, админки, ролей/Telegram-тегов, правил новых участников и lobby для отдельного MafiaAzBot.

## Основные механики

- 148 ролей с постоянным каталогом.
- `калл <роль>` — основной shortcut назначения роли новому/ожидающему участнику.
- `/setrole` — администраторское назначение роли участнику.
- Telegram member tags синхронизируются с русскими названиями ролей.
- Роль и история назначения сохраняются в SQLite.
- При выходе участника текущая роль освобождается, но история остаётся.
- Новый участник получает ограничение на сообщения до назначения роли.
- Кнопка подтверждает ознакомление с правилами флуда и уведомляет владельца; сама по себе ограничение не снимает.
- `/bindrole` из ЛС владельца позволяет привязать роль конкретному участнику.

## MafiaAzBot

Бот не ведёт саму Mafia. Он создаёт lobby:

`1/5 → 2/5 → 3/5 → 4/5 → 5/5`

Lobby закрепляется и обновляется. После пятого участника lobby закрывается и передаётся через `/start@MafiaAzBot`. Если пять игроков не набраны за 5 минут, lobby удаляется.

## Игры и голосование

В каталоге есть:

- Шпион
- Жених и невеста
- Правда или ложь
- Мафия
- Снежный ком историй
- Чёрный ящик
- Бункер

`/game_poll` запускает интерактивный опрос. Каждый участник может выбрать только одну игру и изменить голос. Кнопка `ℹ` показывает короткое описание игры во всплывающем окне.

После завершения опроса выбранная игра назначается на ближайший слот расписания.

## Расписание

Базовый цикл идёт через день:

Вторник → Четверг → Суббота → Понедельник → Среда → Пятница → Воскресенье → снова Вторник.

## Важно для Render

`DB_PATH` должен указывать на постоянное хранилище. Иначе SQLite-история ролей и участников может исчезнуть при пересоздании контейнера.

Для групповых shortcuts нужно отключить Privacy Mode у бота через BotFather.

Запуск:

```text
python bot.py
```
