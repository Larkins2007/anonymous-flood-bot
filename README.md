# Justice Faite Bot

Чистая версия Justice Faite Bot на **aiogram 3 + SQLite**, рассчитанная на запуск через Render.

## Главная логика

### ЛС участника

- `/start` — единая точка входа в Justice Faite.
- Кнопка **«🚪 Хочу вступить»** запускает заявку.
- Сначала подтверждение ознакомления с информационным каналом/правилами.
- Затем желаемая роль.
- Затем обязательная фотография документа с видимой датой рождения.
- Документ отправляется **только владельцу**.
- После отправки кандидат видит только ожидание решения.
- После принятия бот создаёт персональную invite-ссылку с `join request`.
- Telegram-заявка проверяется по ID кандидата; чужой пользователь по этой ссылке автоматически отклоняется.
- После фактического входа используется существующая механика автоматической привязки роли.

### Анонимность

`/anon` и кнопка **«🤫 Анонимная связь»** используют существующую анонимную систему. В интерфейсе обращения автор не раскрывается.

### Дни рождения

Доступны только после вступления:

- `/jf_birthday` — сохранить/изменить дату в формате `DD.MM`.
- `/jf_birthdays` — список сохранённых дат.
- Ежедневный фоновой обработчик поздравляет именинника в основном флуде.

### Владелец — только личный чат

JF-команды владельца не публикуются в группах и доступны только в его ЛС:

`/jf_applications` — активные заявки
`/jf_awards` — кандидаты на достижения
`/jf_award` — выдать достижение
`/jf_iris_sync` — подготовить данные для интеграции с Ирис
`/jf_dashboard` — сводка
`/jf_warn` — выдать предупреждение
`/jf_warnings` — история предупреждений
`/jf_warn_remove` — снять предупреждение
`/jf_rest` — поставить/продлить рест
`/jf_restlist` — текущий рест
`/roles_audit` — аудит ролей
`/bindrole` — ручная привязка роли
`/manage_commands`, `/addcommand`, `/delcommand`, `/commands` — управление пользовательскими командами

## Основной флуд

- `/help`
- `/mafia`
- `/mafia_leave`
- `/spy`
- административные игровые/ролевые команды, уже существующие в основном коде

## Роли

Распознавание не требует строгого формата. Поддерживаются точные названия, слитные варианты, фразы и устойчивые опечатки. Например:

- `казуха` → `Кадзуха`
- `кадзуха` → `Кадзуха`
- `барбара` → `Барбара`
- `чжун ли` → `Чжун Ли`
- `чжунли` → `Чжун Ли`
- `син цю` → `Син Цю`
- `синцю` → `Син Цю`

Занятая роль кандидату не раскрывается.

## Переменные окружения

Обязательные:

- `BOT_TOKEN`
- `ADMIN_ID`
- `PRIMARY_CHAT_ID`

Необязательные:

- `DB_PATH` — по умолчанию `users.db`
- `PORT` — по умолчанию `10000`
- `JF_RULES_URL` — ссылка на информационный канал/правила
- `JF_INVITE_TTL_HOURS` — срок персональной ссылки, по умолчанию 24 часа
- `IRIS_BOT_USERNAME`
- `IRIS_AUTO_AWARDS`
- `IRIS_AWARD_COMMAND`, `IRIS_OLDS_COMMAND`, `IRIS_AWARD_PREFIX`

## Render

`render.yaml` уже содержит запуск:

```bash
pip install -r requirements.txt
python bot.py
```

Бот должен быть администратором основного флуд-чата с правом приглашать пользователей и обрабатывать заявки на вступление. Telegram передаёт ботам `chat_join_request`, а `createChatInviteLink` поддерживает ссылки с обязательным подтверждением заявки. После одобрения бот отзывает использованную персональную ссылку.

## Автоматические награды через Ирис
`/jf_awards` в ЛС владельца запускает запрос `олды` в основном флуде и ждёт ответ Ирис.
После разбора списка бот автоматически отправляет Ирис команды:
- 30+ дней → степень 1;
- 60+ дней → степень 2;
- 120+ дней → степень 3.

Степени и тексты можно изменить в окружении `IRIS_30D_AWARD_LEVEL`, `IRIS_60D_AWARD_LEVEL`, `IRIS_120D_AWARD_LEVEL`, а имя команды Ирис — через `IRIS_AWARD_COMMAND`, `IRIS_OLDS_COMMAND`, `IRIS_AWARD_PREFIX`.
Для автоматического режима требуется доступный bot-to-bot communication flow; если Ирис не получает сообщения от вашего бота, `/jf_awards` не сможет автоматически завершить выдачу.

### Автонаграды за срок в чате
`/jf_awards` в ЛС владельца запускает проверку списка `олды` Ирис. Для каждого найденного и сопоставленного активного участника бот автоматически проверяет все непройденные пороги. По умолчанию используются степени Ирис, заданные в окружении (`IRIS_30D_AWARD_LEVEL`, `IRIS_60D_AWARD_LEVEL`, `IRIS_120D_AWARD_LEVEL`), сейчас это 5 / 6 / 7:

- 30 дней → `!наградить 5 @username`
- 60 дней → `!наградить 6 @username`
- 120 дней → `!наградить 7 @username`

После команды Ирис получает описание отдельной строкой, например: `🌿 60 дней в чате. Участник находится во флуде 2 месяца.` Повторная выдача того же порога блокируется локальным аудитом.

### Проверка

Офлайн-тесты: `python tests/simulation.py`. Реальный Telegram smoke-test требует токен и права бота в основном флуде; изолированная среда сборки не выполняет реальные запросы к Telegram.
