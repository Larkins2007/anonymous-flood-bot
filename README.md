# Justice Faite Bot

Telegram-бот для внутренней инфраструктуры флуд-сообщества Justice Faite.

## Что сохранено

Основные существующие механики текущей версии бота оставлены в `bot.py`: анонимная обратная связь и жалобы, ролевые теги/callback-механика, Mafia/Spyfall, игровые опросы и расписание, админская панель, пользовательская БД и Render health endpoint.

## Что добавлено

- персональные invite-ссылки на вступление с Join Request;
- сохранение заявки в SQLite, переживающее перезапуск процесса;
- получение желаемой роли в свободной форме, в любом порядке с документом;
- обязательная передача фото документа только администратору;
- одобрение/отклонение join request из ЛС администратора;
- автоматическая попытка привязать заявленную роль после одобрения; при занятой роли старую механику `калл` можно использовать без изменения ролевой системы;
- анонимные обращения через ЛС `/anon` без показа автора в сообщении администрации;
- предупреждения с правилами снятия 14/30 дней и ручной обработкой 3+;
- локальные достижения Justice Faite;
- проверки кандидатов в старожилы и лидеры активности;
- списки рест/дней рождения и автоматическое снятие истёкшего рест;
- ежедневное поздравление с днём рождения;
- панель `/jf_dashboard`;
- опциональный hand-off наград в Ирис без публичного копирования его команд.

## Запуск

1. Создай бота через BotFather.
2. Добавь его администратором в основной супергруппе. Для персональных Join Request-ссылок нужны права на приглашение пользователей.
3. Заполни переменные окружения по `.env.example` в Render.
4. Деплой из этого репозитория.

## Важное про вступление

Команда `/jf_invite` создаёт отдельную ссылку Join Request. После первой заявки ссылка сразу отзывается, поэтому она фактически одноразовая.

Telegram позволяет боту получать `ChatJoinRequest`, включая `user_chat_id` для временной связи с кандидатом, и создавать invite links с `creates_join_request=true`. Это используется в этой версии.

## Важное про Ирис

Обычный бот не может читать внутреннюю базу Ирис. Автоматический hand-off поэтому сделан как опциональный адаптер. По умолчанию он выключен. Для прямого bot-to-bot обмена Telegram требует соответствующего режима коммуникации; без него `/jf_iris_sync` формирует безопасный пакет команд для ручной передачи.

## Тесты

`tests/simulation.py` запускает автономную проверку новой SQLite-логики без подключения к Telegram и без настоящего токена.
