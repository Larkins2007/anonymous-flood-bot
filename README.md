# Justice Faite Bot

Telegram-бот на aiogram 3.x для основного чата: правила новых участников, роли/Telegram-теги, Mafia lobby, игровые голосования и расписание.

## Основные механики

- Один основной чат через `PRIMARY_CHAT_ID`.
- Каталог из 148 ролей.
- `калл <роль>` — единственный текстовый shortcut для назначения роли новому/призванному участнику.
- `/setrole` — ручное назначение администратором; название роли разбирается целиком и поддерживает варианты без пробелов вроде `ХуТао`.
- `/syncroles` — заново проверяет актуальные Telegram member tags у всех известных активных участников и сохраняет распознанные роли.
- `/roles_audit` — отчёт владельцу в ЛС об активных участниках и последних изменениях ролей.
- `/bindrole` — резервная привязка роли конкретному участнику из ЛС владельца.
- История ролей сохраняется; при выходе текущая роль освобождается, история остаётся.
- Новый участник получает restriction до подтверждения правил флуда; кнопка подтверждает правила, а назначение роли через `калл` или `/setrole` устанавливает tag и снимает restriction.

## MafiaAzBot

Наш бот не ведёт саму Mafia. Он создаёт lobby 1/5 → 5/5, закрепляет его, обновляет при входе/выходе и передаёт запуск через `/start@MafiaAzBot` после пятого игрока. Недобранное lobby закрывается через 5 минут. Внутренних игровых ролей Mafia нет.

## Игры и голосование

- Шпион
- Жених и невеста
- Правда или ложь
- Мафия
- Снежный ком историй
- Чёрный ящик
- Бункер

`/game_poll` запускает опрос. Название игры меняет голос, `ℹ` показывает описание. Один участник имеет один голос и может его изменить. Сообщение с опросом обновляется после каждого голоса. После завершения опрос открепляется, а результат отправляется отдельным сообщением с упоминаниями проголосовавших за победителя. При ничьей запускается короткий тай-брейк только между лидерами; повторная ничья передаётся администратору.

## Расписание

Расписание хранится внутри бота и используется для определения ближайшего игрового слота и напоминаний; отдельной команды `/schedule` нет.

## Команды участников

- `/help` — помощь.
- `/mafia` — открыть/показать Mafia lobby.
- `/mafia_leave` — выйти из Mafia lobby.
- `/game_poll` — открыть меню запуска игрового голосования.

## Команды администратора в основном чате

- `/setrole` — назначить роль участнику.
- `/syncroles` — обновить знания бота о реальных Telegram-тегах и ролях.
- `/game_poll` — запустить голосование.

## Команды владельца в ЛС

- `/bindrole` — вручную привязать роль участнику.
- `/roles_audit` — получить аудит ролей и последние изменения.
- `/manage_commands` — менеджер пользовательских команд.
- `/addcommand` — добавить пользовательскую команду.
- `/delcommand` — удалить пользовательскую команду.
- `/commands` — список встроенных и пользовательских команд.

## Основной чат

Используется `PRIMARY_CHAT_ID=-1004313546398`, если переменная окружения не переопределена. Роли, голосования, Mafia и расписание работают только в этом чате.

## Render

`DB_PATH` должен указывать на постоянное хранилище, иначе SQLite-история может исчезнуть при пересоздании контейнера.

Запуск:

```text
python bot.py
```

### Синхронизация ролей
`/syncroles` проверяет сохранённых участников основного чата, читает их реальные Telegram-теги, сопоставляет их с каталогом из 148 ролей, принимает ранее выставленные чужим/старым ботом теги под управление и отправляет владельцу полный снимок «роль участника — роль — @username».

## Role snapshot
The owner-facing role snapshot is kept as one editable private message. SQLite remains the machine-readable source of truth because Telegram Bot API does not provide a method to read arbitrary old bot messages back. The snapshot is regenerated from persistent role state after `/syncroles`, role assignment, joins and leaves.

## Persistence on Render
For role/member state to survive redeploys, configure a persistent disk mounted at `/var/data` and set `DB_PATH=/var/data/users.db`. On Render Free, the local filesystem is ephemeral.
