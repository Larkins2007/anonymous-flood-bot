# Justice Faite Bot

aiogram 3 + SQLite, запуск на Render (`python bot.py`). Вход во флуд через бота **удалён**: бот работает с теми, кто уже во флуде, и с анонимной связью.

## Как выдавать награды (Ирис не отвечает ботам)

1. Во флуде напишите Ирис **«олды»**.
2. В ЛС бота отправьте `/jf_awards` и **перешлите ответ Ирис** боту. (Ответ Ирис бот узнаёт и без команды — по пересылке от `iris_dp_bot`.)
3. Бот сопоставит строки с участниками, посчитает пороги (30/60/120 дней по умолчанию) и пришлёт **по одному сообщению на награду** — готовую команду:
   ```
   !наградить 6 @username
   🌿 60 дней в Justice Faite. Участник находится во флуде 2 месяца.
   ```
4. Пересылайте эти сообщения во флуд. Под каждым — кнопки «✅ Выдано» / «⏭ Пропустить»; повторно награда не создаётся.
5. «📦 Очередь» — что ещё не выдано, «🔁 Прислать заново», «✅ Всё выдано».

`/jf_award @user [степень] [описание]` — ручная награда: бот пришлёт готовую команду для Ирис.
Участники без `@username` в команды не попадают — бот перечисляет их отдельно.

## Настройки у каждой команды: `/settings` (ЛС владельца)

Разделы → карточка команды → параметр. У **каждой** команды есть общие настройки (включена, кто может, где работает, пауза, автоудаление) и свои:

| Команда | Свои параметры |
|---|---|
| `/jf_awards` | 3 порога (дни, степень, название), режим «все / только высший», слово и префикс команды Ирис, шаблон описания, username Ирис, кнопки учёта |
| `/rest`, «выдать рест» | максимум дней, объявление во флуд, сообщение об окончании и его текст |
| `/jf_warn` | сроки снятия 1-го и 2-го, объявление во флуде, уведомление в ЛС |
| `/mafia` | минимум игроков, время жизни лобби, закрепление |
| `/spy` | игроки (3–15), количество шпионов (1–3), длительности фаз, число подсказок |
| «калл» | окно после входа новичка, снятие ограничения, отчёт в ЛС |
| Новички во флуде | ограничение до роли, приветствие и его текст, ссылка на правила, уведомление о выходе |
| Поздравления | час и текст |
| `/anon`, жалоба | лимит длины, пауза, текст ответа |
| Свои команды | текст, описание, режим ответа, где/кто/пауза |

Изменения применяются сразу, меню команд Telegram обновляется само (выключенные команды из него исчезают).

## Личная консоль владельца (версия 0.4)

В личных сообщениях владельца доступны `/jf_console`, `/jf_console_refresh`, `/jf_memory` и `/jf_memory_save category | title | text`. Консоль ведёт четыре отдельных редактируемых блока: состояние системы, игровые сессии, доступные модули и память проекта. ID блоков и проектные заметки сохраняются в `jf_console_messages` и `jf_project_memory` внутри общей SQLite-базы. При повторном открытии бот редактирует те же сообщения, а не создаёт новые. Открытая панель автоматически обновляется раз в 5 минут.

Важно: личные сообщения панели — это визуальная консоль, а не сама база данных. Если SQLite-файл потеряется на бесплатном Render, исчезнут также сохранённая память и связи с сообщениями. Для постоянной работы требуется постоянное хранилище (например, Render Disk на тарифе с поддержкой дисков) или миграция на внешнюю БД.

## Команды

Владелец (ЛС): `/jf_console`, `/jf_console_refresh`, `/jf_memory`, `/jf_memory_save`, `/settings`, `/jf_awards`, `/jf_award`, `/jf_dashboard`, `/jf_warn`, `/jf_warn_remove`, `/rest`, `/unrest`, `/bindrole @user Роль`, `/roles_audit`, `/syncroles`, `/who`, `/commands`.
Участники: `/start`, `/help` (показывает только то, что доступно именно вам), `/anon`, `/jf_birthday`, `/jf_birthdays`, `/jf_warnings` (свои), «рестники».
Флуд: `/mafia`, `/mafia_leave`, `/spy`, «калл Роль», `/setrole`, «выдать рест @user 15.09», «снять рест @user», `/who`.

## Переменные окружения

`BOT_TOKEN`, `ADMIN_ID`, `PRIMARY_CHAT_ID`, `DB_PATH`, `LOG_FILE`, `LOG_LEVEL`, `DEFAULT_TIMEZONE_OFFSET_HOURS` (3), `BOT_USERNAME`, `JF_RULES_URL`. Пример — в `.env.example`; файл `.env` сам по себе не загружается ботом, значения нужно задать в окружении или панели хостинга. Для копии проекта явно задайте `ADMIN_ID` и `PRIMARY_CHAT_ID`, не полагайтесь на значения по умолчанию из исходника. Токен бота нельзя публиковать. Остальное — в настройках бота.

## Важно о бесплатном Render

`render.yaml` сейчас использует тариф `free`, который подходит для проверки, но не для надёжного хранения состояния бота. Бесплатный веб-сервис Render может засыпать после 15 минут без входящих запросов; локальные файлы, включая `users.db`, теряются при засыпании, перезапуске и новом развёртывании. На бесплатный веб-сервис нельзя подключить постоянный диск. Значит, могут исчезнуть роли, предупреждения, ресты, дни рождения, настройки, состояние игр и очередь наград.

Перед использованием в основном флуде настройте постоянное хранилище: например, платный сервис Render с диском и `DB_PATH=/var/data/users.db`, где `/var/data` — фактический путь монтирования диска, либо отдельную управляемую БД с миграцией слоя хранения. Сделайте резервную копию текущей SQLite-базы перед переносом. Подробнее: [ограничения Free](https://render.com/docs/free) и [постоянные диски](https://render.com/docs/disks).

## Структура

`bot.py` — ядро (анонимная связь, роли, игры) · `justice_features.py` — рест, предупреждения, дни рождения, сводка · `awards.py` — награды · `cmdcfg.py`, `cmdspecs.py` — реестр команд и настройки · `settings_panel.py` — панель · `ui.py` — единый стиль.

## Тесты

`python3 tests/run_all.py` — работают без Telegram и без установленного aiogram (в `tests/stubs` лёгкие заглушки). Проверяют разбор «олдов», сопоставление, очередь, настройки, маршрутизацию хендлеров, рест/предупреждения/дни рождения, роли, мафию, расписание и **все экраны панели** (лимит 64 байта у `callback_data`).

## Важно

- Бот **не запускался против живого Telegram** (в среде разработки нет сети). Перед боевым запуском проверьте `/start`, `/settings`, `/jf_awards`.
- Парсер рассчитан на присланный формат Ирис: строки с нумерацией, эмодзи, отображаемым именем, статистикой в скобках и сроком справа (например, `🔥 belochki_rulyat (36,5k) — 3 месяца 3 дн`). Статистика в скобках игнорируется. Кликабельные `tg://user?id=…` и Telegram-ссылки имеют приоритет над подписью: она может отличаться от имени профиля. Если ссылку не удаётся надёжно разобрать или участник не найден, бот не угадывает по подписи, а показывает строку для ручной проверки.
- Существующая БД совместима. Старые таблицы заявок/инвайтов не удаляются, но больше не используются.
- Для удаления сообщений (автоудаление) и ограничения новичков боту нужны права администратора во флуде.

## Justice Faite Manager (новое ядро модерации)

В группах доступны естественные команды менеджера и `/jf_manager` со справкой. Полный список, модель рангов, ограничения Telegram и карта переноса 32 разделов Iris находятся в [`IRIS_MIGRATION.md`](IRIS_MIGRATION.md).

**Основные команды:**

- `+Модер @user`, `+Модер 2 @user`, `Повысить @user`, `Понизить @user`, `Снять модер @user`, `Кто админ`.
- `Бан [срок] @user причина`, `Разбан @user`, `Кик @user`, `Кик тихо @user`.
- `Мут [срок] @user причина`, `-Мут @user`, `Муты`, `Проверить мут @user`.
- `Варн @user причина`, `Варны @user`, `Мои варны`, `-Варн @user`, `Варнлист`.
- `Доступ команд`, `Мой доступ команд`, `ДК бан 3`, `ДК бан 6`, `Модер лог`.

Участника лучше указывать ответом на его сообщение. Для `@username` бот должен уже знать ID участника (например, после сообщения или события вступления). Можно использовать числовой Telegram ID. Назначение внутреннего ранга не меняет права Telegram-администратора.

**Стандартные параметры нового ядра:** 3 предупреждения до автозабана, срок хранения предупреждения 30 дней, автоматический бан на 7 дней; бан без срока — бессрочный; мут без срока — 7 дней. Настраиваются командами `Варны лимит`, `Варны период`, `Варны чс`, `Бан период`, `Мут период`. Создатель Telegram-чата сохраняет доступ к восстановлению настроек доступа.

Новые команды `Варн` / `Варны` работают отдельно от прежних `/jf_warn` / `/jf_warnings`, которые сохранены ради совместимости с данными и правилами Justice Faite.

Для работы наказаний добавьте бота администратором с правом ограничивать участников; для тихой чистки и будущих purge-команд потребуется право удаления сообщений. Не выдавайте боту все права без необходимости.

## Justice Faite Manager — дополнительные модули

### Сообщества, заметки и закладки (`jf_community.py`)

- `Создать клан Название` — создать клан; описание можно добавить на следующей строке.
- `Кланы`, `Мой клан`, `Участники клана 12`, `Клан вступить 12`, `Выйти из клана`, `Клан изменить 12 Название`, `Удалить клан 12`.
- `Создать кружок Название`, `Кружки`, `Мои кружки`, `Кружок вступить 4`, `Участники кружка 4`, `Кружок основа 4`, `Выйти из кружка 4`, `Кружок изменить 4 Название`, `Удалить кружок 4`.
- `+Заметка Название` + текст следующей строкой, `Заметки`, `Заметка 12`, `~Заметка 12` + новый текст, `~Название заметки 12` + новое название, `-Заметка 12`.
- Ответом на сообщение: `+Закладка Название`. Для просмотра — `Мои закладки`, `Чатбук`, `Закладка 12`; для удаления — `Удалить закладку 12` или `Исключить закладку 12`.

Кланы и кружки существуют только в конкретном чате. Один участник может состоять в одном клане и в нескольких кружках. Создатель управляет собственными материалами; удалить чужой клан/кружок или модерировать чужую закладку может администратор. Заметки и закладки хранятся в отдельных таблицах `jf_community_*`.

### Настройки Telegram-чата (`jf_chatconfig.py`)

- `+Правила` + текст, `Правила`, `-Правила`.
- `!Название Новый заголовок`, `+Описание чата` + текст, `-Описание чата`.
- Ответом на сообщение `!Закреп`; `!Открепить`.
- `+Чат ссылка`, `Чат-ссылка`, `-Чат ссылка` — управляется только ссылка, которую создал сам бот.
- Фильтры: `+Ссылки` / `-Ссылки`, `+Сайты` / `-Сайты`, `+Чаты` / `-Чаты`, `+Теги` / `-Теги`, `+Боты` / `-Боты`.
- `!Разрешить ссылку https://example.org` и `!Удалить ссылку https://example.org` — исключения для конкретного URL/префикса.

Настраивать чат может Telegram-администратор или внутренний администратор с рангом 3+. Просмотр правил и своей ссылки открыт участникам. Фильтр работает в пределах доступных боту сообщений и прав удаления; он не анализирует медиафайлы и не является заменой Telegram-антиспаму.

### Статистика (`jf_stats.py`)

- `Топ сутки`, `Топ неделя`, `Топ месяц`, `Топ вся`; можно указать лимит, например `Топ 10 неделя`.
- `Моя стата`, `Стата по часам`, `Стата по часам @username`.
- `Чат инфо`, `Чат стата`, `Чат стата по часам`, `Олды`, `Новички`.
- `Список неактив 7 дней`, `Список молчунов 14 дней`.

Ежедневные и почасовые счётчики хранятся в SQLite в разрезе чата и участника. Сбор начинается после обновления. Сейчас учитываются обычные текстовые сообщения, прошедшие через общий обработчик группы; команды, медиа и сообщения, обработанные отдельными игровыми/служебными сценариями раньше него, могут не попасть в счётчики. Время в почасовом отчёте отображается в UTC. Telegram не раскрывает ботам достоверный список пользователей, которые находятся онлайн, поэтому команда «Кто онлайн» не имитируется.

### Служебные команды

В меню Telegram добавлены `/jf_manager`, `/jf_community`, `/jf_chatconfig` и `/jf_stats`. Эти slash-команды дают краткую справку по соответствующему разделу.

### Новые модули Justice Faite Manager (версия 0.3)

В меню Telegram также доступны `/jf_profile`, `/jf_reputation`, `/jf_reports`, `/jf_timers`, `/jf_automod`, `/jf_fun`, `/jf_network`, `/jf_raffles` и `/jf_clean`.

**Профили (`jf_profiles.py`):** `Моя анкета`, `Анкета @username`, `+Ник текст`, `+Звание текст`, `О себе` + текст следующей строкой, `+Девиз текст`, `+Анкета` / `-Анкета`. Поля добровольные и относятся только к текущей группе.

**Репутация (`jf_reputation.py`):** поставь `+` или `+3` ответом на сообщение; посмотри `Рейтинг`, `Топ рейтинга`, `Моя репутация`. Действуют дневные лимиты на поддержку.

**Жалобы (`jf_reports.py`):** ответь на сообщение командой `!Репорт`, причину напиши следующей строкой. Администрация использует `Репортлист` и `Репорт закрыть ID`.

**Таймеры (`jf_timers.py`):** `Таймер через 30 минут`, затем текст напоминания на новой строке; `Таймеры`, `-Таймер ID`, `Сбросить таймеры`. Таймер отправляет только текст и не запускает вложенные команды.

**Автомодерация (`jf_automod.py`):** `+Триггер запрещённая фраза | удалить` либо `+Триггер запрещённая фраза | варн`; список — `Триггеры`, удаление — `-Триггер ID`. Доступно администраторам от внутреннего ранга 3.

**Сетка (`jf_network.py`):** `Сетка создать`, в другой группе `Сетка привязать CODE`, `Сетка чаты`, `Сетка модер`, `Сетка +модер 2 @username`, `Глобан @username причина`, `Глоразбан @username`. Владелец сети проверяется отдельно от владельцев привязанных групп.

**Бесплатные розыгрыши (`jf_raffles.py`):** `+Розыгрыш 2` и текст символической награды следующей строкой; участники используют `Участвую` и `Выйти из розыгрыша`; администратор — `Завершить розыгрыш`, результат — `Победители розыгрыша`. Платных билетов, ставок и денежных призов нет.

**Чистка (`jf_clean.py`):** `-Смс` ответом на сообщение, `-Смс 20` для последних известных сообщений, `!Пург 20` ответом на исходное. Лимит — 100 сообщений за раз. Модуль может удалить только сообщения, чьи ID он успел сохранить после установки, и учитывает ограничение Telegram в 48 часов.

**Развлечения (`jf_fun.py`):** `Рандом 1 100`, `!Данет вопрос`, `!Выбери чай или кофе`, `!Инфа текст`, `!Кубик`, `Пинг`. Ставки и наказания за проигрыш не используются.

**Приветствия и входы/выходы (`jf_chatconfig.py`):** `+Приветствие` + текст, переменные `{имя}`, `{username}`, `{id}`; `-Приветствие`, `Приветствие`, `+Входы`, `-Входы`, `+Выходы`, `-Выходы`.

Статистика и списки активности уже описаны выше. Она накапливается с момента установки; старую историю Telegram восстановить нельзя. Полный список возможностей и отметки частичной реализации — в [`IRIS_MIGRATION.md`](IRIS_MIGRATION.md).
Полный краткий справочник команд — в [`JF_MANAGER_COMMANDS.md`](JF_MANAGER_COMMANDS.md).

### Проверка и права

- `python3 -m compileall -q .`
- `python3 tests/run_all.py`

Тесты работают с локальными заглушками Telegram и SQLite. Живой запуск против Telegram API в этой среде не выполнялся. Выдай боту только необходимые права: удаление сообщений, блокировка участников, закрепление и управление invite-ссылками включаются только для тех функций, которые ты собираешься использовать.
