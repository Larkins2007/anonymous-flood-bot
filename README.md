# Justice Faite Bot

Основа проекта — существующий бот Justice Faite на aiogram 3 и SQLite.

## Контекст команд

### Личные сообщения
`/start` — главное меню и вход во флуд
`/help` — актуальная помощь
`/anon` — анонимное обращение администрации
`/jf_birthday` — сохранить или изменить свой день рождения (только после вступления)
`/jf_birthdays` — список дней рождения (только после вступления)

Команды Justice Faite для владельца доступны только в его личном чате с ботом. Пользовательские игровые команды не публикуются в ЛС.

### Основной флуд
`/help`, `/mafia`, `/mafia_leave`, `/spy` и существующие игровые/административные команды, ограниченные текущей логикой бота.

## Вступление

1. Пользователь запускает `/start` в ЛС и нажимает «Хочу вступить».
2. Бот просит подтвердить ознакомление с информационным каналом/правилами.
3. После «Да» пользователь пишет желаемую роль.
4. Затем отправляет фотографию документа с видимой датой рождения.
5. Фотография передаётся только владельцу.
6. Владелец принимает или отклоняет заявку.
7. При принятии бот создаёт персональную ссылку на основной чат с требованием join request. По ней бот пропускает только заявленного пользователя, затем отзывает ссылку.
8. После фактического входа используется существующая механика автопривязки роли.

## Запуск

Нужны переменные окружения:

- `BOT_TOKEN`
- `ADMIN_ID`
- `PRIMARY_CHAT_ID`
- `DB_PATH` (необязательно, по умолчанию `users.db`)
- `PORT` (необязательно, по умолчанию `10000`)
- `JF_RULES_URL` (необязательно)

Для Render используйте `render.yaml`.

## Проверка

Офлайн-симуляция:

```bash
python tests/simulation.py
```

Она проверяет базу, награды, предупреждения, рест, дни рождения и полный сценарий вступления.
