# Implementation status — v0.11.2

## Исправлено

- Реальная маршрутизация: `Топ богатых` больше не забирается модулем статистики; `Топ рейтинга` направляется в репутацию; `.отн история связи` не перехватывается историей жетонов. `Данет`, `Выбери`, `Инфа` и `Пург` принимают обычные алиасы без обязательного `!`.
- Личные жетоны и искры пары разделены однозначно: `Баланс` / `Кошелёк` показывают личный кошелёк, `.отн искры` — общий парный. Перевод `.отн искры подарок N` сохранён для личных жетонов.
- Фарм: 5–50 личных жетонов, раз в 4 часа, SQLite cooldown + уникальный operation key, безопасный повтор Telegram update, миграция старой записи `farm_daily` без бесплатной немедленной выплаты.
- Социальная связь: добровольное принятие приглашения, 100 общих искр при создании, 30 уровней, XP и 5 искр за первые 10 парных действий каждого участника за московские сутки. Вся динамика записывается в отдельный журнал.
- Существующие пары мигрируются без удаления: начальный баланс фиксируется в журнале; повторное связывание той же пары после разрыва получает новый ключ открытия.
- Изображения действий опциональны: владельческая настройка хранит Telegram `file_id`; сообщение с фото имеет подпись с результатом действия; недействительный файл приводит к резервному текстовому ответу.
- `/settings`: 287 записей (284 политики команд/кнопок и 3 автоматические функции).

## Проверки

- Все 30 существующих офлайн-тестовых модулей прошли по отдельности на локальной SQLite и заглушках aiogram. Модули, затрагивающие маршрутизацию, экономику, отношения, питомцев, профили, статистику, репутацию, чистку и настройки проверены после изменений.
- Добавлен тест фактического первого совпавшего aiogram-обработчика для пересекающихся команд и route-smoke test по всем текстовым политикам каталога с алиасами.
- `python -m compileall -q .` прошёл. ZIP проверен на целостность; checksum приложен.
- Полный агрегированный тест-раннер не удалось надёжно завершить в лимите среды, поэтому подтверждается результат по отдельным модулям, а не единый успешный `tests/run_all.py`.

## Не проверено вживую

- Реальный Telegram Bot API, фактические права администратора, отправка файлов с Telegram `file_id`, работа polling на Render и состояние базы на пользовательском сервисе не проверялись. Архив не загружен и не развёрнут на Render.
- В проекте остаётся безопасная дружеская система, а не полный клон Iris/Celestiana. Сексуальная/взрослая ролевая механика, беременность и сексуальные сценарии с детьми не реализуются.
- Неактивность не уменьшает искры, нет ежедневного decay или штрафов: это сознательное безопасное отличие.
