# Каталог команд Justice Faite Bot

Обозначения: **ЛС владельца** — только пользователь с `ADMIN_ID`; **основной флуд** — чат из `PRIMARY_CHAT_ID`; **участник** — личный чат бота.

## Участники и личные функции

| Команда | Где / кто | Назначение и параметры |
|---|---|---|
| `/start` | ЛС | Открыть меню Justice Faite. Для перехода из лобби «Шпиона» принимает deep-link `/start spyjoin_<ID>` автоматически. |
| `/help` | ЛС и основной флуд | Показать доступные текущему пользователю команды. |
| `/anon` | ЛС | Отправить анонимное обращение администрации; затем отправить текст отдельным сообщением. |
| `/jf_birthday` | ЛС участника флуд-чата | Добавить/изменить дату рождения; бот запрашивает дату в формате `ДД.ММ`. |
| `/jf_birthdays` | ЛС участника флуд-чата | Показать сохранённые дни рождения. |

## Игры в основном флуде

| Команда | Кто | Назначение и параметры |
|---|---|---|
| `/mafia` | Участник | Создать/открыть лобби «Мафии»; подключение и запуск выполняются кнопками. Для старта требуется минимум 5 игроков; запуск передаётся `MafiaAzBot`. |
| `/mafia_leave` | Участник | Выйти из текущего лобби «Мафии». |
| `/spy` | Участник | Создать лобби «Шпиона»; присоединение, запуск, голосование и игровые действия идут кнопками и в ЛС. |
| `/game_poll` | Администратор основного флуд-чата | Создать голосование за игру; параметры и варианты запрашиваются обработчиком команды. |
| `/spy_kick` | Владелец/администратор игры | Исключить игрока из текущей игры «Шпион»; формат подсказывает бот при ошибочном вызове. |
| `/spy_end` | Владелец/администратор игры | Принудительно завершить игру «Шпион». |

## Роли и администрирование чата

| Команда | Где / кто | Назначение и параметры |
|---|---|---|
| `/setrole` | Основной флуд, владелец | Назначить роль: ответить на сообщение участника командой `/setrole Название роли` или использовать `/setrole @username Название роли`. |
| `/syncroles` | Основной флуд, владелец | Синхронизировать известные роли/участников с Telegram. |
| `/bindrole` | ЛС владельца | Ручная привязка роли; отправьте команду без аргументов, чтобы получить подсказку формата. |
| `/roles_audit` | ЛС владельца | Сводка назначенных ролей и последние изменения. |
| `рестники` | Основной флуд | Показать список участников на ресте. |

| `/jf_awards` | Проверка срока пребывания участников и автоматическая выдача настроенных наград через Ирис, если доступен bot-to-bot flow. |
| `/jf_award` | Выдать достижение; бот подсказывает формат при неполном вызове. |
| `/jf_iris_sync` | Повторная синхронизация/выдача наград через Ирис. |
| `/jf_warn` | Выдать предупреждение; формат уточняется ботом. |
| `/jf_warnings` | История предупреждений. |
| `/jf_warn_remove` | Снять предупреждение; формат уточняется ботом. |
| `/rest` и `/jf_rest` | Оформить или продлить рест. |
| `/jf_restlist` | Показать текущий список рестников. |
| `/manage_commands` | Список и управление пользовательскими командами. |

| `/delcommand` | Удалить пользовательскую команду: `/delcommand имя`. |
| `/commands` | Показать список пользовательских и части встроенных команд. |

## Кнопки и автоматические действия

- Личное меню `/start`, заявка на вступление, проверка возраста и обработка заявки — кнопочные сценарии, не slash-команды.
- Лобби «Мафии» и «Шпиона», игровые действия, выбор и голосование — кнопки.
- Кнопки админ-панели открывают соответствующие разделы; текущая реализация части разделов направляет владельца в существующую команду.
- Автоматические напоминания `GAME STARTS` за 30 минут **выключены по умолчанию**. Владелец может включить/выключить их кнопкой в `/admin`. Бот не запускает игру автоматически.
- Пользовательские команды, созданные через `/addcommand`, также становятся доступны в пределах выбранной области.

## Ограничения проверки

Офлайн-тест проверяет синтаксис, наличие ключевых обработчиков и регрессионные условия. Проверить фактическую отправку сообщений, права администратора, заявки, callback-кнопки и интеграцию с Ирис без действительного `BOT_TOKEN`, `ADMIN_ID`, `PRIMARY_CHAT_ID` и доступа к реальному чату невозможно. Никогда не помещайте токен в исходный код.
