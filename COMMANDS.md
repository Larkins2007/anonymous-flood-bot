# Каталог команд Justice Faite Bot

`/admin` или `/panel` — личная панель владельца. В ней доступны сводка, предупреждения, рест-лист, аудит ролей, подготовка наград и персональные настройки команд. В настройках можно включить/отключить каждую команду; это не отменяет проверки прав в самой команде.

## Участники

| Команда | Где | Функция |
|---|---|---|
| `/start` | ЛС | Открыть меню бота; также обрабатывает deep-link игрового «Шпиона». |
| `/help` | ЛС/группа | Показать справку. |
| `/anon` | ЛС | Отправить анонимное обращение администрации. |
| `/jf_birthday` | ЛС | Добавить/изменить день рождения, формат `ДД.ММ`. |
| `/jf_birthdays` | ЛС | Показать список дней рождения. |

## Игры

| Команда | Где / доступ | Функция |
|---|---|---|
| `/mafia` | Основной чат | Создать/открыть лобби «Мафии». Игроки подключаются кнопками. |
| `/mafia_leave` | Основной чат | Выйти из лобби «Мафии». |
| `/spy` | Основной чат | Создать/открыть лобби «Шпиона». Игровые действия выполняются кнопками и в ЛС. |
| `/spy_kick` | По проверке прав | Исключить участника из текущей игры. |
| `/spy_end` | По проверке прав | Завершить игру «Шпион». |
| `/game_poll` | Администратор чата | Создать опрос выбора игры. |

## Роли и администрирование

| Команда | Где | Функция |
|---|---|---|
| `/setrole` | Основной чат, владелец | Назначить роль участнику ответом на его сообщение или по username. |
| `/syncroles` | Основной чат, владелец | Синхронизировать роли/участников. |
| `/bindrole` | ЛС владельца | Ручная привязка роли. |
| `/roles_audit` | ЛС владельца | Сводка ролей и история изменений. |
| `/jf_dashboard` | ЛС владельца | Сводка активных участников, рестов и служебных данных. |
| `/jf_warn` | ЛС владельца | Выдать предупреждение; формат `/jf_warn @username причина`. |
| `/jf_warnings` | ЛС владельца | Посмотреть историю предупреждений участника. |
| `/jf_warn_remove` | ЛС владельца | Снять предупреждение; бот подсказывает формат. |
| `/rest` или `/jf_rest` | ЛС владельца | Оформить/продлить рест. |
| `/jf_restlist` | ЛС владельца | Показать актуальный рест-лист. |

## Награды

| Команда | Где | Функция |
|---|---|---|
| `/jf_awards` | ЛС владельца | Запустить сценарий ручной подготовки наград за стаж. Отправь Ирис `!олды` в основном чате и перешли её ответ боту в ЛС. Бот покажет сводный список получателей и уровней, затем выдаст отдельные команды для ручной пересылки; строки с неоднозначным сопоставлением покажет отдельно. В группу бот команды сам не отправляет. |
| `/jf_iris_sync` | ЛС владельца | Алиас `/jf_awards`. |
| `/jf_award` | ЛС владельца | Выдать локальное достижение Justice Faite, не награду Ирис. Формат `/jf_award @username code название | описание`. |

Каждая команда для Ирис приходит отдельным сообщением. Перешли её в основной флуд вручную. Кнопка «Отметить выданной» фиксирует только ручное подтверждение владельца; бот не может проверить, что Ирис действительно выполнила команду.

## Пользовательские команды

| Команда | Где | Функция |
|---|---|---|
| `/manage_commands` | Владелец | Управление пользовательскими командами. |
| `/addcommand` | Владелец | Создать команду: `/addcommand имя | описание | ответ | область`; область — `all`, `group`, `admin` или `private`. |
| `/delcommand` | Владелец | Удалить команду: `/delcommand имя`. |
| `/commands` | Владелец/доступ по обработчику | Список пользовательских команд. |

## Что намеренно отключено

- Нет кнопки или сценария подачи заявки на вступление во флуд через бота.
- Не регистрируются обработчики `chat_join_request` и маршруты рассмотрения заявок.
- Бот не публикует автоматически `GAME STARTS`, напоминания или другие сообщения о начале игры.
- Нет автоматической отправки команд наград Ирис из бота в группу.
